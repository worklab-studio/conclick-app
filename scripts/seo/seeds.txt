# the harvested children land in kwstore with `seed` set to the line below.
#
# FORMAT
#   `# cluster: <name> | intent: <fallback>` opens a group. Every non-comment
#   line until the next header belongs to that group. score.mjs parses these
#   headers to recover a cluster-level intent fallback, so rows whose own intent
#   is unknown still price correctly instead of collapsing to informational.
#   Blank lines and other `#` lines are ignored.
#
# HARD RULE — NEVER SEED A BARE COMPETITOR BRAND.
#   A bare brand ("plausible", "hotjar") classifies as navigational, which is
#   the ONLY penalty multiplier in score.mjs (x0.6). Every competitor seed here
#   is pre-modified with vs / alternative / pricing / review so it lands on a
#   x1.3 commercial or x1.4 transactional multiplier instead.
#
# POSITIONING
#   Conclick = privacy-first analytics + heatmaps + funnels + revenue
#   attribution in one. ICP = bootstrapped SaaS and ecommerce founders.
#   The defensible wedge is REVENUE ATTRIBUTION — tying Stripe / Paddle / Polar
#   / Lemon Squeezy / Dodo payments back to source, campaign and funnel. Nothing
#   else combines cookieless measurement with multi-processor payment
#   attribution. Heatmaps are NOT a wedge: Matomo, TWIPLA, Piwik PRO, PostHog,
#   Clicky, Silktide and Humblytics all ship privacy-positioned heatmaps, and
#   Umami added them upstream in 3.2.0. Seed heatmaps as INTERPRETATION
#   ("how to actually read a heatmap"), never as a capability claim.
#
# FILE ORDER IS LOAD-BEARING.
#   MONEY clusters come first, MASTERCLASS clusters after. score.mjs walks this
#   file in order and the `money` pick bucket takes from the top, so moving a
#   masterclass cluster above the fold silently starves the commercial pages.
#
# HUB AND SPOKE — why the masterclass clusters exist.
#   The masterclass pages do NOT convert directly, and they are not supposed to.
#   Their job is topical authority, links and AI citation, which is what
#   eventually makes the money pages above rank. Two rules keep them winnable:
#     BROAD IN TOPIC, LONG-TAIL IN QUERY. "what is seo" belongs to HubSpot and
#     Backlinko and is unwinnable for a young domain. "how to tell if your
#     traffic is bots" is winnable and equally on-topic.
#     PREFER A DECISION OR A DIAGNOSIS. "how do i know if...", "why is X showing
#     Y", "should i use A or B". Those are underserved and they build trust.
#   Head terms are conceded on purpose. Do not add them back.
